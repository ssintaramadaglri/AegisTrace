# Support

Use GitHub Discussions for usage questions and GitHub Issues for reproducible defects and accepted feature work. Include the AegisTrace version, Go version, operating system, sanitized workflow, command, expected result, and observed result.

Do not post credentials, private prompts, journals, checkpoints, signing keys, or capability tokens. Follow [SECURITY.md](SECURITY.md) for vulnerabilities.

The project currently provides community support without response-time guarantees. Only the latest minor release is supported.
